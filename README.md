# Veilradio for Android

Standalone Android WebView app using OpenAI and Deezer directly, no Python server.
Enter your own OpenAI API key under **Settings → API**; optionally save it encrypted using Android Keystore.
API costs are separate from ChatGPT. Keys are not committed to source control.

**APK:** Open [GitHub Actions](https://github.com/perfumethief/flagser/actions/workflows/android-apk.yml), select latest successful run, download `Veilradio-Android-APK` from Artifacts, unzip and install `app-debug.apk`.

Original Flagser is preserved at [backup branch](https://github.com/perfumethief/flagser/tree/flagser-backup-2026-10-31).
